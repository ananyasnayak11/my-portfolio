ANANYA S NAYAK — PORTFOLIO PLAYGROUND
Files: index.html, style.css, script.js

LOCAL PREVIEW
1. Extract this ZIP.
2. Open index.html in a browser, or use VS Code + Live Server.

BEFORE PUBLISHING
- Review all project descriptions and achievement wording.
- Add/verify your LinkedIn profile URL (currently the LinkedIn button points to the LinkedIn homepage).
- Internship and certificate wording is based on details shared; confirm dates and exact titles.
- No portrait image is required for this design.

PUBLISH IT FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository, e.g. ananya-portfolio.
2. Upload index.html, style.css, and script.js into the repository root (not inside an extra nested folder).
3. Open repository Settings → Pages.
4. Under Build and deployment, select “Deploy from a branch”, choose “main” and “/(root)”, then Save.
5. Wait for the Pages deployment to finish. GitHub will show a public URL like https://YOUR-USERNAME.github.io/ananya-portfolio/
6. Open that URL on your phone or another device to test it, then share that URL. It is the website link, not the local 127.0.0.1 address.

Alternative: Netlify
- Sign in to Netlify and choose Add new site / Deploy manually, then drag the extracted folder containing these three files into the deploy area. Netlify gives you a public HTTPS URL you can share.
- To update the site later, redeploy the updated files.

This ZIP does not publish itself online. You must complete the hosting steps in your account to make a public URL.
